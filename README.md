Project Overview
FlexiFit is a web-based gym membership and management application
designed to help gyms efficiently manage members, subscriptions, and
attendance while providing members with an easy way to book classes,
track visits, and manage their memberships. ​

The goal of this project
is to build a medium scale, full stack application that
demonstrates modern software development practices and introduces the
team to new tools and technologies.
​
Target audience:​
1)Gym Members – individuals who want to manage their memberships, book
classes, and track attendance. ​
2)Gym Staff – employees responsible for checking in members, managing schedules,
and monitoring attendance. ​
3)Gym Administrators/Owners – users who manage memberships, pricing plans, and
view analytics about gym performance.

Features
-Create and manage a personal account ​
-View and manage membership plans ​
-Book and cancel gym classes ​
-View attendance history ​
-Receive notifications for renewals and upcoming classes 

Technologies used ​
1.Backend: Node.js, Express​
2.Frontend: HTML, CSS, JavaScript​
3.Database:Mongo DB​
4.ODM: Mongoose
5.Development Tool: Visual Studio Code 

Setup Instructions
To run this project locally:
1)Clone the repository from GitHub: git clone <repository-link>
2)Open the project folder in VS Code
3)Install dependencies: npm install
4)Start the application: node app.js
5)Open your browser and go to: http://localhost:3000
